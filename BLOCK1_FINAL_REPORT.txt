🎯 核心功能（4 + 3）
================================================================================

主函数（4 个）：
  1️⃣  get_current_user(authorization, db)
      → 从 Authorization header 解析并验证用户身份
      → 返回：Employee 对象
      → 异常：NotAuthenticated（401）
      → 测试：7 个测试用例 ✅

  2️⃣  get_direct_reports(user, db)
      → 查询用户的直属下级 ID 列表
      → 返回：list[str]（employee_id 列表）
      → 测试：2 个测试用例 ✅

  3️⃣  check_permission(user, action)
      → 根据权限矩阵检查是否有权
      → 涵盖：8 种操作 × 3 种角色 = 24 条规则
      → 返回：bool
      → 测试：8 个测试用例 ✅

  4️⃣  工具函数（2 个）
      a) check_can_view_score(user, target_employee_id, db)
         → 检查是否能查看他人成绩
         → 返回：True 或抛 PermissionDenied（403）
         → 测试：5 个测试用例 ✅

      b) check_can_submit_review(user, target_record_id, db)
         → 检查是否能提交评分
         → 返回：AssessmentRecord 或抛异常
         → 测试：4 个测试用例 ✅

  ✓ get_current_manager(user, db)     - 主管专用依赖
