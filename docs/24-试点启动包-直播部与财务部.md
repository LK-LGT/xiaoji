## 3. 培训提纲（30 分钟）

1. 登录：飞书免登 / 账号
2. 员工：填月计划 → 周计划 → 日计划 → 交成果
3. 主管：审批计划 → 日点评 → 成果确认 → 评分
4. 日历：飞书排班同步；未排班不计应填
5. 异议：在哪里提、多久处理
6. 试点群：问题当天反馈
