# 绩效系统试点执行清单（2 个部门 · 2 周）

> 目标：在**真实业务**里验证「员工愿意填、主管愿意批、HR 少催表」，
> 而不是继续加功能。试点不通过，不进入全公司推广。

---

## 1. 试点选择

- [ ] 选 1 个业务部门（有明确产出/成果）
- [ ] 选 1 个职能部门（流程型工作）
- [ ] 每部门指定 1 名主管 champion
- [ ] HR 指定 1 名试点负责人
- [ ] 技术指定 1 名值班人（处理当天卡点）

## 2. 试点前准备

- [ ] 确认两部门组织、负责人、汇报线已在飞书同步
- [ ] 确认部门已开通对应板块（`department_module`）
- [ ] 确认绩效方案/周期已配置
- [ ] 确认节假日/调休已导入（`workday_rule`）
- [ ] 主管/员工各做一次 30 分钟培训
- [ ] 发一页操作卡（登录、填计划、交成果、审批、申诉）
- [ ] 建试点飞书群，问题当天响应

## 3. 试点周期（2 周）

### 每周一
- [ ] 主管收到/查看团队摘要
- [ ] 员工填本周计划
- [ ] 技术看填报率与异常

### 每周三
- [ ] 检查待审批积压、缺证据、逾期
- [ ] 收集前 5 个卡点并当天修

### 每周五
- [ ] 员工交成果
- [ ] 主管完成审批
- [ ] HR 汇总本周指标

### 第二周末
- [ ] 走一次完整评价：自评 → 主管评分 → 确认 → 归档
- [ ] 走一次异议分支（模拟或真实）
- [ ] 填验收结论

## 4. 试点指标（每周记录）

| 指标 | 目标 | 第 1 周 | 第 2 周 |
|---|---|---|---|
| 计划填报率 | ≥ 80% | | |
| 审批 48h 完成率 | ≥ 80% | | |
| 成果证据完整率 | ≥ 90% | | |
| 员工主动使用率（无需催） | ≥ 70% | | |
| 主管满意度（1–5） | ≥ 4 | | |
| 员工满意度（1–5） | ≥ 4 | | |
| P0/P1 故障 | 0 | | |

## 5. 试点出口

- [ ] 指标达标
- [ ] 无 P0 故障
- [ ] 主管/员工反馈已归档
- [ ] 遗留问题有负责人和排期
- [ ] 业务 owner + 技术 owner 签字

**未达标**：只修卡点，不扩范围；**达标**：进入全公司推广。

## 6. 全公司推广前检查

- [ ] 部署与回滚演练通过
- [ ] 备份/恢复演练通过
- [ ] 通知灰度已确认（无积压、无重复）
- [ ] 培训材料与操作卡定稿
- [ ] 客服/值班机制确定
- [ ] 数据口径与报表经 HR 确认
