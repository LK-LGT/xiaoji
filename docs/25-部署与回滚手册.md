# 部署与回滚手册（2026-11-27）

> 目标：一条命令拉起 **PostgreSQL + 后端 + agent-service + 前端 nginx**，
> 并且每一步都能验证、能回滚。

## 1. 组成

| 服务 | 端口 | 说明 |
|---|---|---|
| frontend | 8080 → 容器 80 | nginx 托管 dist，反代 `/api/` → backend:8000/v1/ |
| backend | 8000 | FastAPI + Alembic；`/health` / `/ready` |
| agent | 8800（仅内网） | AI 模型服务；必须配 `AGENT_SHARED_SECRET` |
| postgres | 5432（仅内网） | 生产数据库；数据卷 `pgdata` |

## 2. 前置

- Docker / Docker Compose
- `backend/.env`、`agent-service/.env` 已配置（**不要提交到 git**）
- 至少 2 GB 内存

## 3. 启动

```bash
cd framework
export POSTGRES_PASSWORD='<强密码>'
docker compose up -d --build
docker compose ps
```

后端容器启动时会先执行 `alembic upgrade head`，然后启动 uvicorn。

## 4. 验证

```bash
# 后端就绪（DB + 迁移版本）
curl http://localhost:8000/ready

# 前端
curl -I http://localhost:8080/

# 前端经 nginx 访问后端
curl http://localhost:8080/api/health

# agent-service（从 backend 容器内或宿主机映射端口）
curl http://localhost:8800/health
```

预期：

- `/ready` 返回 `{"status":"ready","database":"ok","alembicVersion":"0050_..."}`
- 前端能打开登录页
- 后端日志无迁移错误

## 5. 数据库迁移

```bash
docker compose exec backend alembic current
docker compose exec backend alembic upgrade head
```

⚠️ **不要**在应用启动前用 `AUTO_CREATE_TABLES=true` 建表；
那会让后续 Alembic 迁移撞“表已存在”。

## 6. 备份

### PostgreSQL
```bash
docker compose exec -T postgres pg_dump -U perf -d perf > backup-$(date +%Y%m%d-%H%M).sql
```

### SQLite（本地/小规模）
```bash
python - <<'PY'
import sqlite3
src=sqlite3.connect('backend/data/perf.db')
dst=sqlite3.connect('backend/data/perf.db.bak')
with dst: src.backup(dst)
print('ok')
PY
```
⚠️ 直接 `cp` 会漏掉 WAL 里的新表；用 `sqlite3 .backup` 或同时复制 `-wal/-shm`。

## 7. 回滚

### 代码回滚
```bash
git checkout <上一个稳定 tag>
docker compose up -d --build
```

### 数据库回滚
```bash
# 仅回退一版迁移（确认可逆时）
docker compose exec backend alembic downgrade -1

# 或从备份恢复
docker compose exec -T postgres psql -U perf -d perf < backup-YYYYMMDD-HHMM.sql
```

## 9. 生产注意

- `backend/.env` 与 `agent-service/.env` 必须用密钥管理注入，不要打进镜像
- `PASSWORD_LOGIN_ENABLED=false`、`TEST_USERS_ENABLED=false`
- `AUTO_CREATE_TABLES=false`
- `AGENT_SHARED_SECRET` 两端一致；为空时 agent-service 启动失败
- 前端只暴露 nginx；agent/postgres 不要映射到公网
