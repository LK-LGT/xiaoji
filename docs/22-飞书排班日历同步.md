# 飞书排班 → 员工工作日历（2026-11-27）

## 口径

**排班与考勤的事实源是飞书考勤**，系统不再自己推导「周一~周五上班」。

- 飞书 `shift_id == "0"` ⇒ 休息；
- 其它 `shift_id` ⇒ 上班；
- 人工请假 / 出差（`workday_rule`）优先于排班；
- 某月同步成功、但查不到某人某天 ⇒ `UNASSIGNED`（未排班）：
  - **不计入应填天数**
  - 员工工作台显示「飞书未排班」告警

## 数据表

| 表 | 作用 |
|---|---|
| `employee_shift_day` | 员工 × 日期 × 是否上班（飞书同步结果） |
| `shift_sync_run` | 某月同步批次；只有 `SUCCESS` 才允许判「未排班」 |

## 命令

```bash
# 演练（不写库）
python backend/scripts/sync_feishu_workdays.py --month 2026-11

# 确认写库
python backend/scripts/sync_feishu_workdays.py --month 2026-11 --confirm
```

每日自动同步：

```dotenv
FEISHU_WORKDAY_SYNC_ENABLED=true
FEISHU_WORKDAY_SYNC_HOUR=2
```

开启后每天同步「当月 + 下月」。下月未排满时状态为 `PARTIAL`，
**不会**把未排班数据当成事实；等 HR 排完再次同步即可。

## 安全阈值

未排班员工占比 > 10% 时，同步状态记为 `PARTIAL`，不建立 SUCCESS 覆盖。
只有确认排班已完整发布，才使用：

```bash
python backend/scripts/sync_feishu_workdays.py --month 2026-12 --confirm --allow-partial
```
