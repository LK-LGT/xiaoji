## 一、系统概览（给非技术人员的解释）

### 这个系统做什么

**员工绩效管理智能体** = 飞书 + 后台系统 + AI 助手

```
┌─────────────────────────────────────────────────┐
│ 员工 → 自评表（飞书审批）                        │
│     ↓                                             │
│ AI 机器人 → 检查你填的是否有问题                 │
│     ↓                                             │
│ 主管 → 打分表（飞书审批）                        │
│ ↑        AI 给出建议                             │
│ │        规则引擎算分                            │
│ │                                               │
│ HR → 审核、导出、查询                            │
└─────────────────────────────────────────────────┘
```

### 为什么需要 AI

**AI 的作用**：
1. ✅ **审校**：发现员工填的自评有没有漏项、数字有没有明显错误
2. ✅ **建议**：根据数据给主管一个打分建议（主管可以不同意）
3. ✅ **总结**：自动生成评语初稿（主管改一改就行）
4. ✅ **查询**：员工问"我这月绩效怎么样"，AI 秒回答

**AI 的限制**：
- ❌ 不能改你的分数（只能建议）
- ❌ 不能改你的自评内容（只能提醒）
- ❌ 所有分数和定级都是规则算出来的（可复算，绝不偏心）

## 三、员工操作流程

### 3.1 收到自评邀请

**怎么看**：
- 📬 飞书私聊收到机器人消息："请填写 10 月自评"
- 或者登后台，看"我的绩效" → "待完成"

**点进去后看到的**：
```
┌──────────────────────┐
│ 10 月自评表          │
├──────────────────────┤
│ 必填：                │
│ □ 本月重点工作成果   │
│ □ GMV 完成数字       │
│ □ 满意度得分         │
│                      │
│ 可选：                │
│ □ 存在的挑战          │
│ □ 改进方向            │
│                      │
│      [提交]          │
└──────────────────────┘
```

### 3.2 如何填写

**建议**：

1. **从 Excel 里复制数字** —— 别手打，容易错
2. **必填项一个都不能漏** —— 填完后有个"检查"按钮，点一下看有没有问题
3. **工作成果要量化** —— 不要写"工作认真"，要写"完成 10 个项目，零投诉"
4. **如果有不确定的地方，留个问号** —— 主管看到了会主动问

### 3.3 提交前自检

**提交前一定要问一遍自己**：

- ☑ 数字对吗？（最好和 Excel 对一遍）
- ☑ 大项都填了吗？（没有红色感叹号）
- ☑ 有错字吗？（检查一遍）

**如果有问题，点"检查"**：

系统会告诉你：
- ⚠️  这个数字看起来很大，对吗？
- ⚠️  这个项目完成了吗？
- ✅ 看起来不错，可以提交

> **重点**：这个"检查"不是 AI 在做坏事，是在帮你节省时间。如果 AI 建议有问题，你可以选择忽视。

### 3.4 提交 + 等待主管评分

**提交后**：
- 自评表锁定（改不了了，除非撤销重填）
- 主管会在 1-2 天内收到通知
- 你的自评内容只有主管和 HR 能看

**怎么知道主管已经打分**：
- 飞书收到通知
- 或登后台看"我的绩效"状态从"待评" → "已评"

### 3.5 查看最终结果

**怎么查**：

1. 登后台 → "我的绩效" → "10 月"
2. 看到这样的界面：

```
┌─────────────────────────┐
│ 你的 10 月绩效          │
├─────────────────────────┤
│ 总分：78.5              │
│ 等级：B（达成）          │
│                         │
│ 各项分数：              │
│ • GMV:        85 (A)   │
│ • 退款率:     72 (C)   │
│ • 满意度:     76 (B)   │
│                         │
│ 评语：                  │
│ 本月总体表现达成预期... │
│                         │
│      [申诉]   [详情]   │
└─────────────────────────┘
```

### 3.6 对结果有意见？申诉

**什么时候申诉**：
- 你认为分数明显不公平
- 数据有误（比如 GMV 算错了）
- 评语说的事实不符

**怎么申诉**：
1. 点"申诉"按钮
2. 填写原因（具体，别就说"不同意"）
3. 提交 → HR 会在 3 天内回复

**常见申诉理由**：
- ✅ "退款率数据有误，应该是 5%，不是 8%"
- ✅ "我的 10 月数据包含 9 月的尾款，不能对比"
- ❌ "我觉得我不应该是 B，应该是 A"（没有数据依据）

## 四、主管操作流程

### 4.1 收到下属自评

**怎么看**：
- 📬 飞书收到消息："你有 5 位下属提交了自评"
- 或登后台 → "待评分" → 看列表

### 4.2 评分步骤

**打开一个下属的记录**：

```
┌──────────────────────────────┐
│ 评分表：李四                 │
├──────────────────────────────┤
│ 自评数据：                   │
│ • GMV: 1,250,000            │
│ • 完成度: 104%               │
│ • 满意度: 4.5/5.0           │
│                              │
│ ⚡ AI 建议：                  │
│ 基于上述数据，建议打分...     │
│ • 综合评级：A                │
│ • 理由：GMV 超额 4%，...     │
│                              │
│ 你的评分：                   │
│ 综合评级：[ 选择 ]           │
│           ▼                  │
│           A | B | C         │
│                              │
│ 评语（可编辑）：             │
│ [李四本月表现优秀...]        │
│                              │
│      [同意 AI] [修改] [保存] │
└──────────────────────────────┘
```

**三个选择**：

1. **同意 AI** —— 直接确认
2. **修改** —— 改成你觉得合适的等级和评语
3. **保存** —— 锁定这个评分（改不了了）

### 4.3 注意事项

| 场景 | 处理方式 |
|---|---|
| 员工分数明显和自评不符 | 查一下数据源，可能数据错了。如果是数据错，通知 HR |
| 你想改 AI 建议的等级 | 可以改。改了之后填上你的理由（方便事后复盘） |
| 你的下属人太多，有点烦 | 先标记"待定"，明天继续。系统会提醒你 |
| 有个下属数据看不懂 | 不用猜。直接问 HR 或点"咨询"，消息会转给数据负责人 |

### 4.4 部门复核（部门负责人）

**如果你还是部门负责人**，需要再审一遍下属主管的评分：

1. 登后台 → "部门复核"
2. 看所有下属（和他们的主管评分）
3. 可以加意见，但**不能改分数**（分数由规则引擎算，是固定的）
4. 点"确认" → 进入 HR 终审

## 五、部门复核

### 5.1 谁该复核

**部门负责人**需要在 HR 之前复核一遍，作用是：
- 发现明显的不公平（比如同一个岗位，一个 A 一个 C）
- 给下级主管反馈（"这个评价理由我看不懂"）
- 给 HR 一个参考意见

### 5.3 如果有异常怎么办

**异常 ① ：同岗位分数差异太大**

例：两个运营专员，一个 A，一个 C。

处理：
1. 点进两条记录对比
2. 如果真的差异大（数据都对），可以给 HR 标个"待确认"
3. 不能自己改分（分数是规则引擎算的）

**异常 ② ：评语写得不清楚**

例："基本达成"（太模糊）

处理：
1. 给出具体反馈："要写清楚哪些项达成、哪些项不足"
2. 主管会收到反馈，可以修改评语
3. HR 之前会再看一遍

## 六、HR-运维操作

### 6.1 发起月度考核

**步骤**：

1. **登后台** → "考核管理" → "新建任务"
2. **填基本信息**：
   - 月份：2026-10
   - 参评部门：选择（可多选）
   - 评分级别：3 级（普通员工 → 主管 → 部门负责人）

3. **上传指标定义**（Excel）：
   - 必填列：指标代码、指标名称、权重、满分、及格线
   - 示例：
     | 代码 | 名称 | 权重 | 满分 | 及格 |
     |---|---|---|---|---|
     | gmv | GMV | 40% | 100 | 60 |
     | feedback | 满意度 | 30% | 100 | 50 |
     | refund | 退款率 | 30% | 100 | 50 |

4. **审批 → 发布**
   - 系统会冻结这一版的指标
   - 即使中途改配置，这个任务的指标不变

5. 飞书机器人自动推送通知给员工和主管

### 6.2 监控进度

**登后台** → "任务监控"：


### 6.3 处理数据异常

**情况 ① ：某员工的分数"不对"**

检查清单：
1. 指标值对吗？ → 查 Excel 源数据
2. 权重对吗？ → 查任务的指标定义表
3. 规则对吗？ → 一般不会错（规则引擎是确定的）

如果确实数据错了：
- 改源数据（Excel） → 系统重新读取 → 分数自动重算
- **不要手工改分数**（会破坏可追溯性）

**情况 ② ：考勤异常为什么没自动扣分**

这是**正常的、设计如此**。原因：
- 制度上"考勤不自动扣分"
- 目的是让主管有酌情权
- 如果要强制扣分，需要改制度（不是改系统）

### 6.4 导出 + 发放

**步骤**：

1. **登后台** → "结果管理" → 月份 → "导出"
2. **选择导出格式**：
   - 基础报表（姓名、分数、等级）
   - 详细报表（+各项指标）
   - HR 专用（+申诉信息、审批链路）

3. **导出后**：
   - 一般发给各部门 HR
   - HR 再通知员工查看结果

### 6.5 查询和报表

**后台提供的查询**：

| 查询 | 访问方式 |
|---|---|
| 我要看某员工的全部详情 | "员工搜索" → 输入名字 → 看本年所有月份 |
| 我要看某部门这月的平均分 | "部门汇总" → 选部门 → 看分布 |
| 我要查"不公平"的情况 | "异常检测" → 系统列出松紧差异 |
| 我要对标前月数据 | "趋势对比" → 选月份 → 看涨跌 |
| 我要给 CEO 报数据 | "一键报告" → 系统生成 PPT/Excel |

### 6.6 权限管理

**谁能看什么**：

| 操作 | 普通员工 | 主管 | 部门负责人 | HR |
|---|---|---|---|---|
| 看自己的结果 | ✅ | ✅ | ✅ | ✅ |
| 看下属的结果 | ❌ | ✅ | ✅ | ✅ |
| 看全部门 | ❌ | ❌ | ✅ | ✅ |
| 看全公司 | ❌ | ❌ | ❌ | ✅ |
| 导出数据 | ❌ | ❌ | ❌ | ✅ |
| 改分数 | ❌ | ❌ | ❌ | ❌ |

> **关键**：没有人能改分数。分数只由规则引擎算。

### 6.7 系统维护

#### 日常巡检

| 检查项 | 频率 | 怎么检查 |
|---|---|---|
| 数据同步 | 每天 | "系统监控" → "数据同步" → 看最后一次同步时间 |
| 飞书通知 | 每天 | 看有没有失败的通知 → 如失败，触发重发 |
| 存储空间 | 每周 | "系统" → "磁盘使用" → 如超过 80%，清理日志 |

#### 异常处理

**问题 ① ：某个员工一直卡在"待评"**

原因可能：
- 主管忘了 → 催一下
- 飞书通知没送到 → 手动推送一次
- 系统卡死 → 重启后台（运维）

**问题 ② ：考勤数据一直没导入**

原因可能：
- Excel 格式错 → 下载模板重新上传
- 飞书权限问题 → 联系 IT
- 接口超时 → 改成手工导入，接口就绪后切换

**问题 ③ ：AI 经常不回答**

原因可能：
- 模型服务故障 → 系统自动降级（用模板代替）
- Prompt 有问题 → 联系开发改进
- 超时（正常） → 自动重试 3 次

## 七、AI 相关 FAQ

### Q：AI 会不会改我的分数？

**不会**。系统设计上 AI 没有修改权限。AI 能做的只是：
- 建议（你可以不同意）
- 提醒（数据可能有问题）
- 草稿（评语初稿，主管改了再用）

### Q：AI 的建议有时候是错的，怎么办？

这很正常。解决方式：

1. **发现 AI 建议有问题** → 主管不同意，改成你的评分
2. **反馈给 HR** → HR 会记录这个问题
3. **系统会学习** → 下个月 Prompt 会改进

### Q：我的隐私数据会被 AI 看到吗？

**部分脱敏了**：
- AI 看不到你的姓名（就是代码 E001）
- AI 看不到你的详细自评内容（只看指标数字）
- AI 看不到你的电话、邮箱等

AI 看到的：
- 指标数字（必须的，不然没法打分）
- 是否有异常（必须的，不然没法预警）

### Q：如果 AI 服务故障了，考核还能继续吗？

**能**。系统会自动降级：

| 智能体 | 故障时怎么办 |
|---|---|
| 填报辅导 | 不追问，简化表单 |
| 证据校验 | 不检查，直接进主管队列 |
| 评级建议 | 不给建议，主管自己打分 |
| 总结 | 用模板评语（主管需要自己写） |

**总之，AI 故障不影响流程，只是人工工作量会增加**。

## 八、常见问题

### 我找不到某个员工的成绩？

**检查清单**：
- [ ] 这个月的考核发起了吗？（问 HR）
- [ ] 这个员工在这个月的参评部门里吗？
- [ ] 这个员工的自评已经主管打分了吗？
- [ ] 你有权限看这个员工的成绩吗？（员工只能看自己，主管只能看下属）

### 下属一直没收到考核通知？

**解决办法**：
1. 确保他/她已经加了这个飞书应用（让他搜"绩效小助手"）
2. HR 在后台手动推送一次通知
3. 或直接告诉下属登后台看

### 我想改已经提交的自评？

**如果还在"评分前"**：
- [ ] 点"撤销" → 重新填 → 再提交

**如果已经主管打分了**：
- ❌ 不能改了（考核已锁定）
- 如果数据真的错了，申诉 → HR 会处理

### 分数和我预期的差很多？

**先不急着申诉，检查**：
- [ ] 指标值对吗？（最关键）
- [ ] 权重对吗？（比如 GMV 本来 40%，改成了 30%）
- [ ] 等级标准对吗？（85 分以上才是 A 吗？）

确认真的错了才申诉。

### 我能看到其他员工的成绩吗？

**按身份分**：
- 员工：只能看自己
- 主管：能看下属的
- 部门负责人：能看自己部门的
- HR：能看全部

如果你觉得权限不对，找 IT。

## 九、故障处理

### 问题：我登不进系统

**检查**：
1. 网络连接好吗？
2. 密码对吗？（试试重置）
3. VPN 连上了吗？（如在公司外）
4. 能登飞书吗？（如果飞书也登不了，问 IT）

### 问题：页面加载很慢

**可能的原因和解决**：
- 网络差 → 换个网络，或等等再试
- 人太多 → 避开 9 点-10 点高峰期
- 浏览器缓存 → Ctrl+Shift+Delete 清缓存，重新登

### 问题：表单提交不了

**重新试一遍**：
1. 检查必填项都填了吗？
2. 数字格式对吗？（比如一万不要写 1w，要写 10000）
3. 换个浏览器试试
4. 如果还是不行，截图保留，找 IT

### 问题：看到奇怪的提示（比如"权限不足"）

**这通常是权限问题**：
- 你的账号可能被禁用了
- 或者飞书应用权限没给
- 找 HR / IT 检查权限

### 紧急联系

| 问题类型 | 联系人 |
|---|---|
| 登录 / 密码 | IT Help Desk |
| 考核政策 / 申诉 | HR 部（绩效负责人） |
| 数据错误 | HR 数据组 |
| 系统故障 / 报错 | 技术支持（钉钉/企业微信） |
